# Anti-Gravity Website

A futuristic website for an anti-gravity technology company, built with the latest web technologies.

## Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **Language:** TypeScript

## Getting Started

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Run the development server:**

   ```bash
   npm run dev
   ```

3. **Open the local server:**

   Visit [http://localhost:3000](http://localhost:3000) in your browser.

## Features

- **Modern & Clean UI:** Designed with a focus on aesthetics and user experience.
- **Dark Mode Support:** Built-in dark mode support (configured in `globals.css`).
- **Performance Optimized:** Utilizing Next.js best practices for speed and SEO.

## Editor Setup

If you are using VS Code, this project includes a `.vscode/settings.json` file to configure the editor.
Specifically, it suppresses "Unknown at rule" warnings for the new Tailwind CSS v4 `@theme` syntax.
