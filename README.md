## 🚀 Getting Started

Quickstart to run this portfolio locally.

### Prerequisites
- Node.js 18+ (recommended)
- npm or yarn
- Git

### Installation
```bash
# Clone the repository (replace with your repo URL if different)
git clone https://github.com/Michael-Franklyn-MDF/practice.git
# If your repo is named differently, update the URL above.

# Navigate to project directory
cd practice

# Install dependencies
npm install
# or
# yarn

# Run development server
npm run dev
# or
# yarn dev

# Open your browser and navigate to:
# http://localhost:3000
```

## 📦 Deployment
Deployed on Vercel for performant hosting and instant global CDN.

- Automatic deployments on git push (connect GitHub repository to Vercel) 🔁
- Live URL: https://practice-gamma-bay.vercel.app

Deploy Your Own:
> Show Image

Quick steps:
1. Log in to https://vercel.com and import your GitHub repository.  
2. Choose framework preset (Next.js) and root directory (if not the repo root).  
3. Configure environment variables (if required) and click Deploy.  
4. Optionally set up a custom domain in your Vercel dashboard.
