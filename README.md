Overview

Practice is a comprehensive developer toolkit designed to streamline building modern Next.js applications with best practices baked in. It offers a structured architecture, integrated styling with Tailwind CSS, and a suite of reusable components to accelerate development and ensure maintainability.

Why Practice?

This project simplifies setup, enforces code quality, and provides a modular foundation for creating performant, styled, and scalable Next.js websites. The core features include:

🎯 🛠️ Next.js Configuration: Centralized settings for optimized build, runtime, and deployment strategies.
🚦 🧹 ESLint Integration: Enforces code standards and web vitals compliance for maintainable codebases.
🎨 🖌️ Tailwind CSS Setup: Seamless styling with utility-first CSS integrated via PostCSS.
🧩 🔧 Reusable Components: Modular UI elements like Navbar, Hero, Projects, and Contact to speed up development.
📊 📁 Centralized Data Models: Structured data for projects and experiences supporting dynamic content.
⚙️ 🚀 Developer-Centric Architecture: Focused on performance, scalability, and ease of customization.

Installation

Build practice from the source and install dependencies:

Clone the repository:

❯ git clone https://github.com/Michael-Franklyn-MDF/practice
Navigate to the project directory:

❯ cd practice
Install the dependencies:

Using npm:

❯ npm install
Usage

Run the project with:

Using npm:
